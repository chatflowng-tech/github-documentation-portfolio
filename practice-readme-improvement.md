# Practice Sample: Improving a Project Introduction

## About this sample

This is a fictional practice exercise, not paid client work.
The draft was prepared with AI assistance and is intended for
review and learning.

## The task

Rewrite a vague project introduction so a beginner can
understand the tool, its purpose, and its limitations.

## Before

This tool sorts files. Pick a folder and run it.

## After

# Folder Helper

Folder Helper is a fictional desktop tool that groups files
into folders by file type.

For example, it places photos in a Photos folder and PDF
documents in a Documents folder.

## Who it is for

People who want to organize a cluttered folder without
moving each file individually.

## How it works

1. Choose the folder you want to organize.
2. Preview the proposed changes.
3. Confirm the changes to move the files.

These steps describe the imagined tool. They have not
been tested against a real application.

## Safety notes

Before using any file-organizing tool, back up important
files and test it on copies first.

## What needs clarification

Before publishing documentation for a real tool, I would
ask its developer:

- Which operating systems are supported?
- What happens when two files have the same name?
- Can users undo changes?
- Are files in subfolders included?
- Which file types are supported?

## Why the rewrite is clearer

- It explains the tool's purpose.
- It identifies the intended user.
- It gives a concrete example.
- It separates instructions from safety notes.
- It identifies missing information instead of inventing answers.
